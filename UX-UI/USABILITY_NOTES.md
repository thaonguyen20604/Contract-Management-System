# Usability Notes

## Strengths
- Clear module separation by business function
- Role-based entry points reduce clutter for each user type
- Desktop form layout supports transactional data entry
- Multi-language resources improve accessibility for Vietnamese and English users

## Potential UX Issues
- Several screens may be dense if the user has many data fields on one page.
- No formal accessibility documentation or color-contrast review was found.
- The support chatbot introduces a mixed experience that may not be consistently integrated into the overall screen design.
- The repository contains design PDFs, but no explicit usability test result or heuristic evaluation artifact was found.

## Observation Status
These notes are derived from implementation evidence only and should be validated through actual user observation before being treated as confirmed UX findings.
